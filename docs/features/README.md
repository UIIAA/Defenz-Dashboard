# docs/features/

Cada feature deste projeto comeca com um spec aqui antes de virar codigo.

## Convencao
`feature-NNN-slug.md` onde NNN e numero sequencial e slug e descricao curta em kebab-case.

Status do spec: `Draft` -> `Approved` -> `In Progress` -> `Done`.

## Por que spec-first
Implementacoes sem spec acumulam divida — checklist do CLAUDE.md global do orquestrador exige spec aprovado antes de codigo.
